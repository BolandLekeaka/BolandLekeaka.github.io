Course Overview: IT3203 — Intro to Web Development

This course introduces essential topics for modern web development, including HTML, CSS, JavaScript, responsive design, and client–server communication. Students learn both theoretical foundations and practical implementation through hands-on projects.

Course Objectives

  • Understand core web technologies such as HTTP, HTML, CSS, and JavaScript.
  • Develop responsive and mobile-friendly webpages using modern best practices.
  • Design multi-page websites with consistent layout and reusable components.
  • Analyze how browsers process requests and render web content.
  • Apply fundamental concepts like statelessness, caching, and performance optimization.

Milestones & Project Work

Milestone 1

Build a multi-page static website demonstrating HTML semantics, page structure, navigation, and basic styling with a shared CSS file.

Milestone 2

Add research-driven content, improve the layout using grids and tables, and integrate images, references, and structured sections to enhance clarity and depth.

Milestone 3

Combine responsive design techniques with JavaScript functionality. This milestone includes implementing mobile-first layouts, writing media queries, ensuring cross-device usability, and creating interactive components such as quizzes or dynamic behaviors using an external JavaScript file.
